# ADR-004 · 演示环境部署到 AWS 单实例, 生产形态用 IaC 描述

日期: W1 决策, W6 实施
状态: 已接受

## 背景

JD 第 7 节 P0 清单明确要求「使用 Docker Compose 一键启动」「建立 GitHub Actions」「部署到 AWS,
并提供可复现实验说明」三项并列。原方案因 AWS 账号注销而用免费第三方托管替代, 现账号可用, 应补齐。

约束: 个人自费, 预算上限约 $10/月; 求职窗口 4–6 个月; 单人运维。

## 决策

**演示环境 = Lightsail 单实例 + docker compose + Caddy 自动 HTTPS; 生产形态 = Terraform 描述, 不实际开支。**

| 项 | 选择 | 月成本 |
|---|---|---|
| 计算 | Lightsail Micro (1 GB / 2 vCPU / 40 GB SSD / 2 TB 流量), 含公网 IPv4 与流量 | ~$7 |
| 数据库 | Postgres 容器跑在同一实例, 数据卷挂 EBS/实例盘 | $0 |
| 备份 | 每日 `pg_dump` 上传 S3 + 生命周期规则 30 天过期 | ~$0.1 |
| 前端 | 同实例 Caddy 托管静态产物(同源, 无 CORS/混合内容问题) | $0 |
| 域名 | 一个便宜域名, Caddy 自动签 Let's Encrypt 证书 | ~$1 (年费摊薄) |
| **合计** | | **~$8** |

刻意**不用**的服务及理由(这本身是面试素材):

- **ALB / NAT Gateway**: 单实例无需负载均衡; NAT Gateway 约 $32/月, 是新手账单事故第一名。
- **RDS**: 托管数据库最低档已接近整台实例价格, 而演示场景不需要多可用区与自动故障转移。
- **ECS Fargate**: 原 Codex 方案的选择。容器编排在单服务、单人、零弹性需求下是纯负债。

## 成本护栏(实施时必须一并完成)

1. AWS Budgets 设 $5 / $10 两级告警到邮箱;
2. 不申请多余弹性 IP(未挂载的公网 IPv4 单独计费);
3. CloudWatch 日志组设保留期(默认永不过期, 会缓慢累积费用);
4. 仓库 README 写明"演示环境可能已下线, 本地 `docker compose up` 是权威复现路径"。

## 生产形态如何证明

`infra/terraform/` 描述目标架构(ALB + ECS Fargate + RDS Multi-AZ + CloudFront + WAF), `terraform plan`
可在 CI 里跑通但不 apply。ADR 记录切换阈值:

> 当 (a) 日活 > 1k 或 (b) 需要多实例滚动发布零停机 或 (c) 数据库 RPO 要求 < 5 分钟时,
> 切换到 Fargate + RDS 形态; 在此之前单实例的成本/复杂度比更优。

## 面试问答

**Q: 为什么不用你原来那套 serverless?**
原系统是常驻低频监控, serverless 合理。重构版的目标函数变了: 单人快速迭代 + 任何人可复现 +
长任务状态机, 单体 + 单实例更优。`legacy/` 保留了原 8 个 Lambda 与 IaC 备份, `docs/aws-mapping.md`
是逐组件映射表。

**Q: 这套架构能扛多少量?**
不知道确切数字, 但我写了切换阈值和 Terraform 目标形态; 需要时的迁移路径是明确的, 不是"以后再说"。

## 后果

- 优点: JD 的 AWS 要求真实满足; 成本可控; 演示链接与本地复现双路径。
- 缺点: 单点, 实例挂了演示即不可用 → 缓解措施是本地 compose 始终可用, 且 README 显式说明。
- 风险: 求职结束后忘记关实例会持续扣费 → Budgets 告警 + 日历提醒。
