## 已完成的关键实现（W1）

- **迁移器**（`apps/api/app/db.py`）：API 启动时按序执行 `migrations/*.sql`，
  用 `schema_migrations` 台账保证只跑一次。刻意不走 docker-entrypoint-initdb.d，
  让裸跑 / CI / Docker 三条路径共用同一建表逻辑。W2 起换 Alembic。
- **`/ingest`**：三类事件（sensor_state / heartbeat / rfid_scan）统一入口。
  幂等键 = (device_id, 业务标识, ts)，唯一索引在 `0002_ingest_idempotency.sql`。
  UPSERT 带 `WHERE 旧.ts < 新.ts` 做乱序保护 —— 修复了原 Lambda 无条件覆盖的缺陷。
- **`/status`**：沿用 legacy status-api 的 60s 心跳超时语义，实现下沉到 service 层。
- **device-sim**：YAML 剧本模式 + CSV 真实数据回放模式。数据源是队友仓库导出的
  344 条真实读数（`apps/device-sim/seed/waterlevel_readings.csv`）。
- 测试 24 条全绿（device-sim 6 / policy_engine 5 / api 13）。
